# 01. Обзор проекта SkillMap

## Кратко

SkillMap — веб-приложение, которое по карьерной цели студента строит **интерактивный граф навыков**, сравнивает его с профилем пользователя (**Gap Analysis**) и формирует **пошаговый план обучения** с ресурсами.

## Проблема

Студенты тонут в курсах, статьях и видео. Нет ясного понимания:
- какие навыки нужны для профессии;
- в каком порядке их изучать;
- сколько времени это займёт;
- где именно у них пробелы.

## Решение

1. Пользователь выбирает профессию (Frontend-разработчик, Data Scientist и т.д.).
2. Система показывает граф навыков с зависимостями.
3. Пользователь отмечает известные навыки.
4. Система подсвечивает пробелы и генерирует план по неделям.
5. По мере прогресса всё пересчитывается.

## Ключевые модули (MVP)

| Модуль | Что делает |
|--------|------------|
| Интерактивная карта | Граф (React Flow), цвета статусов, карточка навыка, отметка, «следующий шаг» |
| Gap Analysis | Сравнение профиля с эталоном → освоенное / недостающее + % |
| Персональная траектория | План по неделям, ресурсы, «Что делать на этой неделе», пересчёт |
| Дашборд | KPI, уровень (новичок/продвинутый/эксперт), ближайшие шаги |
| Auth + профиль | Регистрация, JWT, GitHub OAuth, часы/нед, цель |
| Каталог + онбординг | ≥10 профессий, квиз за 3 минуты |
| Экспорт | PDF + публичная ссылка |
| Админка | CRUD профессий, навыков, связей, ресурсов |

## Критерии приёмки (Must)

- Карта ≥10 профессий, кликабельные узлы, описание + сложность + ресурсы
- ≥3 уровня подготовки
- Gap Analysis корректно показывает недостающие навыки
- Дашборд обновляется в реальном времени
- Работает в Chrome, Firefox, Safari, Edge + адаптив
- Генерация карты ≤ 5 секунд
- TypeScript + ESLint, ключевые сценарии покрыты тестами
- Новый пользователь строит первую карту ≤ 3 минуты без инструкции
- Рекомендации — бесплатные/доступные ресурсы (Stepik, Coursera и т.п.)
- PDF или публичная ссылка
- План на 2–3 месяца с шагами в часах/проектах

## Что НЕ делаем в MVP

- Импорт из LinkedIn (Won't)
- Бейджи / геймификация (Could)
- Напоминания (Could)
- Шаринг в соцсети (Could)
- Фильтры карты и режим «по навыку» (Should/Could)
- Смена цели с сохранением пересечений (Should)

## Позиционирование vs конкуренты

- **roadmap.sh** — сильный граф + AI, но платный AI и нет явного Gap по сохранённому профилю, нет русского.
- **Skillmaps.ru** — ближайший российский аналог, но карта = список, не граф; план в waitlist.
- **SkillMap** выигрывает: бесплатный граф + Gap + план по срокам + русский + импорт GitHub/Stepik (Should).
