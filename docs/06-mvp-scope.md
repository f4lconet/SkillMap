# 06. MVP Scope (MoSCoW + план)

## Must (делать сейчас)

| Модуль | Что входит |
|--------|------------|
| Auth + профиль | Регистрация, вход, сброс пароля, профиль (цель, уровень, часы), хранение прогресса |
| Каталог + онбординг | ≥10 профессий, поиск/фильтр, выбор уровня, квиз (цель→уровень→часы→навыки) |
| Карта | Граф, zoom/pan, карточка навыка, цвета, отметка, подсветка следующего шага |
| Траектория | Генерация, план по неделям, ресурсы, «Что делать на этой неделе», пересчёт |
| Gap Analysis | Списки освоенных/недостающих, %, PDF-отчёт |
| Дашборд | KPI, уровень, диаграммы, ближайшие шаги |
| Интеграции | Только **ручной ввод** навыков |
| Экспорт | PDF + публичная ссылка |
| Админка | Профессии, навыки, связи, ресурсы |

## Should (после MVP)

- Смена цели (с сохранением пересечений)
- Фильтры карты
- Удаление аккаунта
- Управление подключениями

- Журнал изменений

## План этапа 2 (по неделям)

| Неделя | Фокус | Результат |
|--------|-------|-----------|
| 1 | Инфраструктура, auth, каталог, онбординг | Регистрация работает, каталог, квиз |
| 2 | Интерактивная карта | Граф + цвета + карточка + отметка |
| 3 | Gap, дашборд, траектория | Отчёты и план |
| 4 | PDF, публичная ссылка, админка, контент | Экспорт + CRUD + наполнение |
| 5 | Стабилизация, тесты, сдача | MVP по критериям приёмки |

---

## Сценарии приёмки (Must)

1. **Первая карта ≤ 3 мин**  
   Главная → профессия → регистрация/онбординг → карта с цветами и следующим шагом.

2. **Еженедельное обновление**  
   Дашборд → отметить навык → пересчёт % / карты / плана.

3. **Публикация**  
   Профиль → публичная ссылка → гость видит read-only.

4. **Редактор**  
   Админка → навык + связи → проверка циклов → публикация.
