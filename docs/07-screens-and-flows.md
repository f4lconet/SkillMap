# 07. Экраны и User Flows

## Перечень экранов

| № | Экран | Роль | Ключевые элементы |
|---|-------|------|-------------------|
| 1 | Главная (лендинг) | Гость | Hero, пример карты, CTA «Выбрать профессию», «Демо-карта» |
| 2 | Регистрация / Вход | Гость | Email/пароль, GitHub OAuth, восстановление |
| 3 | Каталог профессий | Гость/Студент | Поиск, фильтр направления/уровня, ProfessionCard |
| 4 | Онбординг-квиз | Студент | Шаги: цель → уровень → часы → известные навыки |
| 5 | Интерактивная карта | Студент | React Flow canvas, легенда, боковая/нижняя карточка |
| 6 | Карточка навыка | Студент | Описание, сложность, ресурсы, кнопки статуса |
| 7 | Траектория | Студент | Недели, ресурсы, блок «Что делать на этой неделе» |
| 8 | Gap Analysis | Студент | % , списки освоенных/недостающих, PDF |
| 9 | Дашборд | Студент | KPI, уровень, ближайшие шаги |
| 10 | Интеграции | Студент | Ручной ввод (GitHub/Stepik — Should) |
| 11 | Профиль | Студент | Цель, часы, публичная ссылка |
| 12 | Публичная карта | Гость | Read-only граф + % |
| 13–14 | Админка | Редактор | CRUD профессий/навыков/связей/ресурсов |

**Навигация студента (после онбординга):**  
Карта · Траектория · Gap Analysis · Дашборд · Интеграции · Профиль

---

## User Flow: первая карта (критичный)

```
Главная
  → «Выбрать профессию» / Каталог
  → Выбор ProfessionCard
  → (если не авторизован) Регистрация / Вход
  → Онбординг:
       1. Подтверждение цели
       2. Уровень (начинающий / средний / продвинутый)
       3. Часов в неделю
       4. Отметить известные навыки (поиск + checkbox)
  → Редирект на Карту
       - mastered = зелёные
       - available = можно кликать
       - locked = серые
       - подсветка «следующего шага»
```

Целевое время: **≤ 3 минуты**.

---

## User Flow: еженедельный прогресс

```
Дашборд
  → блок «Что делать на этой неделе»
  → клик по навыку → Карточка навыка
  → «Освоено» + уровень
  → backend обновляет UserSkill
  → frontend инвалидирует gap / plan / dashboard / graph
  → всё обновляется без полной перезагрузки
```

---

## User Flow: публичная ссылка

```
Профиль → включить «Публичная карта»
  → копировать URL
  → Гость открывает /public/{token}
  → видит граф read-only + % до цели
  → нет кнопок отметки
```
