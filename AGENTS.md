## 1. Что за проект

**SkillMap** — веб-приложение для студентов и молодых специалистов.

**Главная ценность:** пользователь выбирает профессию → видит интерактивный **граф навыков** с зависимостями → отмечает то, что уже знает → получает **Gap Analysis** (пробелы) и **персональный план** по неделям с ресурсами.

**Не делаем:** маркетплейс курсов, соцсеть, полноценный LMS, LinkedIn-импорт (Won't в MVP).

**Целевая аудитория:** студенты IT-направлений (Frontend, Data Science, DevOps, Product и т.д.).

**Ключевые критерии приёмки MVP:**
- ≥10 профессий с графами
- Граф кликабельный, цвета статусов, карточка навыка
- Gap Analysis + % соответствия
- План по неделям + «Что делать на этой неделе»
- Дашборд обновляется при отметке навыка
- PDF-экспорт + публичная ссылка
- Первая карта нового пользователя ≤ 3 минуты
- Время генерации карты ≤ 5 сек
- Русский интерфейс

Полные критерии и аналитика: `docs/01-project-overview.md`

## 2. Стек (не менять без запроса)

| Слой | Технология |
|------|------------|
| Frontend | **Next.js** (App Router) + **TypeScript** + **Tailwind CSS** |
| Архитектура frontend | **Feature-Sliced Design (FSD)** |

**UI-kit** уже частично реализован (цвета, Button, Input, Badge, SkillNode, ProfessionCard и т.д.) — см. `docs/04-ui-kit.md` и код в `apps/frontend/src/shared/ui` (или перенесённый из `src/shared`).

## 5. MVP Must (что писать сейчас)

См. подробно `docs/06-mvp-scope.md`.

Кратко:

- Auth (email/пароль + GitHub OAuth) + профиль
- Каталог ≥10 профессий + поиск/фильтр
- Онбординг-квиз (цель → уровень → часы → известные навыки)
- Интерактивная карта (React Flow): узлы, связи, zoom/pan, цвета, карточка, отметка, подсветка следующего шага
- Gap Analysis (списки + %)
- Траектория (недели + ресурсы + «Что делать на этой неделе» + пересчёт)
- Дашборд (KPI, уровень, ближайшие шаги)
- Ручной ввод навыков
- PDF + публичная ссылка
- Админка: профессии, навыки, связи, ресурсы (базовая)

**Не делать в MVP:** LinkedIn-импорт, бейджи, напоминания, шаринг в соцсети, фильтры карты, смена цели (Should), удаление аккаунта (Should).

## 6. Ключевые пользовательские сценарии

1. **Первая карта ≤ 3 мин**  
   Главная → Выбрать профессию → Онбординг (уровень, часы, навыки) → Карта с цветами и «следующим шагом».

2. **Еженедельное обновление**  
   Дашборд → «Что делать» → Отметить навык «Освоено» → пересчёт % / карты / плана.

3. **Публикация**  
   Профиль → включить публичную ссылку → гость видит read-only карту.

4. **Редактор**  
   Админка → добавить навык + связи → проверка циклов → публикация.

## 7. Правила написания кода (агент)

### Frontend
- TypeScript strict.
- Компоненты в FSD-слоях.
- Стили — только Tailwind + CSS-переменные из UI-kit.
- Не хардкодить цвета — использовать токены (`accent`, `text`, `success` и т.д.).
- Граф — React Flow. Состояния узлов: `mastered | in-progress | available | locked | selected`.
- Состояние пользователя (цель, навыки) — через API + React Query / SWR / Zustand (выбери одно и держись).
- Все тексты UI на русском.

### Backend
- FastAPI + Pydantic v2 + SQLAlchemy 2.0 (или SQLModel).
- JWT access + refresh.
- Алгоритмы Gap Analysis и генерации плана — в `services/`.
- Топологическая сортировка графа при генерации плана.
- Проверка циклов при сохранении зависимостей.
- OpenAPI/Swagger актуален.

### Общее
- Не добавляй зависимости без необходимости.
- Не пиши «заглушки навсегда» — если функция Must, делай рабочую версию.
- Коммиты и названия — понятные, на английском или русском (как в проекте).
- Тесты: ключевые сценарии (auth, отметка навыка, Gap, генерация плана).
